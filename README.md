- **Tech Stack:** HTML, CSS, JavaScript
- **Features:** Search jobs, track applications, interactive dashboard.

#### 2. 💰 [PersonalFinanceTracker](https://github.com/varshitram7-oss/PersonalFinanceTracker)
An intuitive tool for managing budgets, tracking expenses, and visualizing financial health.
- **Tech Stack:** HTML, CSS, JavaScript, LocalStorage
- **Features:** Expense categorization, dynamic charts, monthly budget setting.

#### 3. 🌤️ [Weather Dashboard](https://github.com/varshitram7-oss/Weather-Dashboard)
A premium dark-themed weather dashboard providing real-time forecasts and interactive metrics.
- **Tech Stack:** HTML, CSS (Glassmorphism), JavaScript (Mock Weather Engine)
- **Features:** 5-day forecast, search history, interactive temperature conversion, and location quick-buttons.

#### 4. 📋 [TaskFlow Kanban Board](https://github.com/varshitram7-oss/TaskFlow-Kanban)
A beautiful Kanban-style task management board using native drag-and-drop mechanics.
- **Tech Stack:** HTML, CSS, JavaScript, HTML5 Drag & Drop API
- **Features:** Color-coded priority badges, column-wise stats, list filters, and task search.

#### 5. 🔑 [Password Vault](https://github.com/varshitram7-oss/Password-Vault)
A secure-by-design password generator and vault interface for storing credentials safely.
- **Tech Stack:** HTML, CSS, JavaScript, LocalStorage
- **Features:** Custom length & character generator, password strength evaluator, search/filter vaults.

#### 6. 🏆 [QuizMaster App](https://github.com/varshitram7-oss/QuizMaster-App)
A timed quiz application featuring category selection, leaderboard tracking, and visual analytics.
- **Tech Stack:** HTML, CSS, JavaScript, LocalStorage
- **Features:** Multi-difficulty questions, animated countdown timer, interactive progress tracker, and summary graphs.
